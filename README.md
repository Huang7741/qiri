# 栖日 Qiri

Windows 本地运行的个人影视助手，用于整理签到、追剧日历与任务日志。目前供开发者本人本机使用，不提供公共托管服务。

## 当前功能

- 普通签到：支持手动检查、按北京时间定时执行，以及重复签到保护。
- 更新日历：展示栖影网站的未来排期，并与资源上新、TMDB 播出日期分别标记。
- 运行日志：记录任务状态、错误原因，支持筛选、查询和导出。
- 本地管理页面：默认仅监听 127.0.0.1，使用 Python 与 SQLite，无需 Docker 或 Hyper-V。

浏览器接入已完成本人账号的连接、今日已签到状态读取和日历同步验证。首次签到写请求仍需后续实际运行验证。

## 栖影官方 API 接入计划

本项目正在申请独立的栖影开发者应用。官方 OpenAPI 接入代码已准备，待应用审核通过后完成本人账号授权与实际验证。

计划使用的权限：

| 权限 | 用途 |
| --- | --- |
| 账户与积分 | 查看本人账户信息、积分及相关记录 |
| 每日签到 | 每日普通签到 |
| 搜索与资源 | 查询关注影视及资源更新 |
| 解锁资源 | 后续按本人设定的条件与积分上限解锁 |
| 读取通知 | 展示本人站内通知 |
| 标记通知已读 | 按本人操作更新通知状态 |

不申请投稿、删除投稿或修改他人内容的权限。遵守网站的请求频率、调用额度、资源权限和积分规则。

本地授权回调地址：

```text
http://127.0.0.1:8101/oauth/callback
```

## 运行与数据边界

- 程序运行在本人 Windows 电脑上。
- 浏览器接入需要浏览器及已登录的栖影标签页保持打开；Cookie 留在浏览器中。
- 官方 API 方式需使用本项目自行申请、获批的应用凭证，不使用其他软件的应用凭证。
- 官方 API 不提供网站未来排期接口；未来播出信息需单独接入相应数据源。
- 115 网盘转存为后续计划，尚未实现，需要独立的网盘授权。
- 网站密码、Cookie、Token、应用凭证和个人运行数据不上传至本仓库。
